# Oikos

οἶκος, the household.

The index at **[corvardt.com](https://corvardt.com)**. A short body of work is
not a grid of cards, it is a set of channels you tune between, so the page is
one tube and each project is a station on it.

## The channels

| | | |
| --- | --- | --- |
| 1 | **[Keraunos](https://keraunos.corvardt.com)** | Lightning striking the earth, live, plotted on a world map as it happens |
| 2 | **[Steropes](https://steropes.corvardt.com)** | Random numbers drawn from that same lightning, graded against four statistical tests in front of you |
| 3 | **[Tyche](https://tyche.corvardt.com)** | Forty random Ethereum keys a roll, read against the chain. A free lottery at one in 2^160 |
| 4 | **[Klepsydra](https://github.com/corvardt/klepsydra)** | A desktop card reading your Claude usage off your own machine |
| 5 | **[Nostos](https://github.com/corvardt/nostos)** | A media downloader that runs on your own machine |

The first three are live at their own address. The last two run on your machine
rather than on anyone's server, so they are marked with a square and point at
the repository you clone them from.

## Using it

Point at a record to tune it, click to open it.

| | |
| --- | --- |
| `↑` `↓` or `j` `k` | tune |
| `1`–`9` | jump to a channel |
| `↵` | open |
| `t` | switch medium |

`dark` is phosphor on black, `light` is ink on chart stock. The choice follows
you into every project on the domain.

Nothing is fetched from anyone else: no trackers, no analytics, no fonts from a
third party. The page is static files served from one origin.
